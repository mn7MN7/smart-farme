# 🌾 Smart Farm IoT System (نظام المزرعة الذكية المتكامل)

مشروع هندسي متكامل لأتمتة وإدارة المزارع والتحكم البيئي الآلي باستخدام تقنيات إنترنت الأشياء (IoT) ومتحكمات الأردوينو. يهدف المشروع إلى تقليل التدخل البشري، ترشيد استهلاك المياه، حماية المحاصيل من الظروف الجوية، وتأمين مرافق المزرعة بشكل ذكي ومستدام.

---

## 🚀 الأنظمة الفرعية للمشروع (Sub-Systems)

* **1. نظام مراقبة المناخ والحرارة (Climate Control):**
  * مراقبة درجات الحرارة والرطوبة النسبية داخل بيئة المزرعة باستخدام مستشعر `DHT11`.
  * التحكم التلقائي بمروحة التهوية (عبر Relay) في حال ارتفاع الحرارة، أو تشغيل التدفئة (LED) في حال انخفاضها لضمان بيئة مثالية.
* **2. نظام الري الذكي ومستوى المياه (Smart Irrigation):**
  * قياس نسبة رطوبة التربة ومستوى المياه في خزان الري عبر حساسات تناظرية وعرض القراءات على شاشة LCD.
  * تفعيل مضخة المياه تلقائياً عند جفاف التربة بشرط توفر منسوب مياه كافٍ في الخزان لحماية المضخة.
* **3. نظام حماية المحاصيل من الأمطار (Rain-Sensing Window/Roof):**
  * الاعتماد على حساس مطر لاستشعار قطرات الماء وتفعيل الحماية فوراً.
  * تحريك محرك سيرفو تلقائياً لإغلاق النوافذ أو سحب المظلات عند هطول الأمطار وإعادتها للوضع الافتراضي عند توقفها.
* **4. نظام الأمان وبوابات الدخول (RFID & Keypad Access Control):**
  * تأمين بوابات المزرعة عبر طبقتي حماية: إما بإدخال رمز سري عبر لوحة مفاتيح رقمية (4x4 Keypad) أو عبر مسح بطاقة تعريف ممغنطة (RFID MFRC522).
  * التحكم بفتح وإغلاق الأبواب بصفة آمنة باستخدام محركات سيرفو مزدوجة.
* **5. نظام التغذية الآلي للحيوانات (Automated Livestock Feeding):**
  * نظام ميكانيكي مبسط مرتبط بزر تحكم (Push Button) ومحرك سيرفو لتنظيم تقديم وجبات الطعام بضغطة زر.

---

## 📂 هيكلية الملفات البرمجية (File Structure)

* `1.c++`: كود نظام حماية الأمطار وحركة المظلات التلقائية عبر حساس المطر والسيرفو.
* `2.c++`: كود نظام الري الذكي ومراقبة مستوى خزان المياه مع شاشة LCD ووحدة الريليه.
* `3.c++`: كود نظام تكييف ومراقبة حرارة ورطوبة الجو عبر مستشعر DHT11 والمروحة والتدفئة.
* `4.c++`: كود نظام الأمان المتكامل للتحكم ببوابات المزرعة باستخدام قارئ RFID ولوحة المفاتيح.
* `5.c++`: كود نظام التغذية الآلي للحيوانات المرتبط بزر التشغيل ومحرك السيرفو.

---

## 🛠️ المكونات الهاردويرية المستخدمة (Hardware Components)

* لوحة تحكم Arduino (Uno / Mega)
* مستشعر الحرارة والرطوبة (`DHT11`)
* قارئ البطاقات اللاسلكية (`RFID MFRC522`) مع البطاقات الممغنطة
* لوحة مفاتيح رقمية (`4x4 Keypad`)
* محركات سيرفو متعددة (`Servo Motors`)
* شاشات عرض (`16x2 LCD Display`) مع محول `I2C`
* وحدات ترحيل (`Relay Modules`) للتحكم بالأحمال الكهربائية
* حساسات تناظرية (حساس رطوبة التربة، حساس مستوى المياه، وحساس المطر)
* أزرار ضغط (`Push Buttons`) ومقاومات وأسلاك توصيل

---

## ⚙️ طريقة التشغيل والتثبيت

1. توصيل المكونات الهاردويرية لكل نظام فرعي حسب البنات (Pins) المحددة في بداية كل ملف برمجي.
2. فتح بيئة التطوير (`Arduino IDE`) وتثبيت المكتبات اللازمة (`LiquidCrystal_I2C`, `DHT sensor library`, `MFRC522`, `Keypad`, `Servo`).
3. رفع الكود الخاص بكل وحدة إلى لوحة الأردوينو المناسبة لبدء التشغيل[cite: 21, 22, 23, 24, 25].
